# Phase 0 spike — go/no-go (2026-09-28)

Throwaway runs used a temporary `HOME`/`USERPROFILE`; nothing touched real agent homes.

## (a) rulesync 22.0.0 for hooks — GO (hooks only)

- Canonical events (camelCase) map correctly. Claude: `sessionStart, beforeSubmitPrompt, postToolUse, stop,
  subagentStart, subagentStop, sessionEnd, notification` → `SessionStart, UserPromptSubmit, PostToolUse, Stop,
  SubagentStart, SubagentStop, SessionEnd, Notification`. Codex: same set plus `permissionRequest` →
  `PermissionRequest` (timeout forwarded).
- Per-agent commands via override blocks `claudecode.hooks` / `codexcli.hooks`; a top-level `"hooks": {}` is required.
- `preserveUnownedHooks: true` keeps hand-written hooks ("Preserving unowned hook on Stop: command:user-own-hook")
  and writes `.rulesync-hooks-lock.json` beside each hooks file. `delete` MUST be `false`.
- `.claude/settings.json` is merged (unrelated keys `model`, `env` preserved; rulesync adds `$schema`).
- Quoted commands with spaces (`"C:/Users/Juan dela Cruz/…/harness-hook.cmd" claude`) survive unchanged.
- `--output-roots` is ignored with `--global`; the output root is `HOME`/`USERPROFILE`. Multi-home method:
  run codexcli generation with `HOME`/`USERPROFILE` pointed at a staging dir, then distribute `hooks.json` to the
  three Codex homes with the existing hard-link model (one file shared by `personal`, `cy`, `feu`).
- NO-GO for the `rules` feature: it rewrites `~/.claude/CLAUDE.md` / `~/.codex/AGENTS.md` wholesale, which would
  destroy owner content. Policy stays on managed-block `@import` (Claude) and hard links (Codex).

## (b) Codex hook payloads — confirmed from `codex-rs/hooks/schema/generated/*.command.input.schema.json`

| Event | Required fields |
|---|---|
| SessionStart | cwd, hook_event_name, model, permission_mode, session_id, source, transcript_path |
| UserPromptSubmit | + prompt, turn_id |
| PostToolUse | + tool_input, tool_name, tool_response, tool_use_id, turn_id |
| Stop | + last_assistant_message, stop_hook_active, turn_id |
| SubagentStart | + agent_id, agent_type, turn_id |
| SubagentStop | + agent_id, agent_transcript_path, agent_type, last_assistant_message, stop_hook_active, turn_id |
| SessionEnd | cwd, hook_event_name, reason, session_id, transcript_path |
| PermissionRequest | + tool_input, tool_name, turn_id |

Field names match Claude Code's; Codex adds `turn_id` and `model`. Codex also supports `SubagentStart`
(spec §6 table said "—"; corrected by this spike).
